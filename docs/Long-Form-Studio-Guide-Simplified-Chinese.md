# H3 剧本制作中心（本地增强版）

这一版没有替换 H3 的提示词系统，也没有替换你的 Ollama。它新增一个编排层：先把长故事按实际动作和对白动态拆成 4–15 秒片段，再把每段建立成普通 H3 Studio 工程。

## 使用顺序

1. 双击 `H3-Start.bat` 打开 http://127.0.0.1:8766/ 。
2. 顶部选择“剧本制作”。右上角“界面”可切换简体中文、繁体中文、English、日本語；这个选项只改变界面，不改变剧本。
3. 当前 Studio 工程会作为人物、图片、风格和 ComfyUI 设置的母版。
4. 先选择“项目输出语言”，再粘贴任意语言的完整故事或剧本。视觉风格、角色圣经和连续性规则都是补充项；剧本和分镜编辑内容使用项目语言，最终发给 H3 的镜头指令统一为英文，对白使用项目语言。
5. 点击“创建项目并配置资产卡”，先上传角色、服装、道具、环境和角色声线素材。
6. 保存卡库后选择：
   - “本地 AI 智能拆分”：调用当前配置的 Ollama 或 LM Studio。
   - “不用 AI，动态估时”：模型离线时也能用；同样不是固定时长。
7. 检查每段的地点、动作、结束画面、逐字对白和关键帧提示词。
   - 可新增片段、在当前片段后插入、删除片段，或上下调整顺序；系统会自动重排片段序号。
   - 删除片段只会把它移出当前长片与最终合并顺序，不会删除已经生成的视频文件。
8. 每段可上传最多 12 张“本段专属关键帧”，或调用本地生图模型追加；这些图片不会进入共享卡库，也不会影响其他段。
9. 每段可以单独重做视频提示词、写修改要求、选择 ComfyUI 视频工作流，并直接生成或重新生成视频。
10. “创建并打开 H3”：把这一段转为普通 H3 工程，并回到 Studio 深入调整；“只补缺失 / 过期工程”不会重做未变化的成果。
11. 在“视频与成片”中查看各段版本、生成用时与保存目录，选择采用版本。所有段准备好后可自动或手动合并最终成片。

## 三类项目分别在哪里管理

- “剧本制作”管理长片、短剧和剧集。进入后先看到独立的“剧本项目管理”页，可搜索、分页、新建、载入和删除项目。
- “镜头工作室”管理普通单镜头 H3 工程。打开“镜头工作室 → 已保存项目”即可载入或导出；它与剧本项目分开，避免列表混在一起。
- “互动故事”管理可游玩的分支故事。打开“互动故事 → 已保存故事”即可切换或继续。

剧本项目打开后按五个页面工作：**项目与剧本 → 卡组与角色 → 剧集规划 → 分镜制作 → 视频与成片**。画幅、分辨率、质量配方、采样步数、自动合片和视频工作流库统一放在右上角“制作设置”，不会挤在分镜页面。

“连续性规则”是可选的高级约束，例如“主角左手戴表”“伤口在右眉”“同一场戏不换服装”“镜头轴线不越过”。不填写完全可以；角色卡、服装卡、道具卡和环境卡仍会负责主要的一致性。

## 时长逻辑

- 每段 4–15 秒，按对白语速、可见动作、反应、运镜稳定和结尾停顿综合估算。
- 小于 4 秒的细碎节拍合并；大于 15 秒的内容在自然动作或剧情边界拆开。
- 对白保持逐字，不通过加速朗读硬塞。
- 连续生成时要注意 .mmh3 通常携带约 1.6 秒前段运动；界面显示的是每个生成片段的时长，成片拼接时会有重叠。


## 制作资产卡库

每个制作项目拥有独立卡库；切换制作项目时角色和素材不会串用。本地 AI 智能拆分会同时读取剧情、分镜信息和本项目卡库，并在每个片段中记录它选择的角色、服装、道具、环境和声线。只有 AI 不可用或选择结果不合格时才退回本地文字匹配。

- 角色卡：一个角色一张卡，可上传多张身份参考图；本段出现 1–3 个角色时分别传独立图，超过 3 个时自动生成角色总览拼图。
- 服装卡：单独管理并绑定角色，避免把换装误当成角色身份变化。
- 道具卡：用于关键、独特或反复出现的物件；按本段文字选择，不相关道具不会传入。
- 环境卡：用于反复出现且布局需要一致的场景，推荐清楚的广角参考图。
- 角色声线卡：绑定角色，建议上传 2–15 秒无音乐、无混响、只有一人说话的干净音频。
- 每张角色声线卡可单独选择简体中文、繁体中文、English 或日本語；新建时默认继承项目输出语言，可按角色覆盖。
- 风格卡：直接输入文字即可作为全片风格约束；风格图完全可选，只作分析上下文，不进入九张生成参考图配额。

卡片列表默认折叠成一行摘要；点击右侧箭头才展开编辑，一次只展开一张，避免角色或声线较多时页面拥挤。

## 两种语言设置的区别

- 界面语言：只控制按钮、栏目和帮助文字，保存在当前浏览器，不影响项目内容。
- 项目输出语言：保存到项目数据中。本地 AI 可以读取任意输入语言；剧本和分镜编辑内容使用选定语言，最终 H3 提示词里的场景、镜头、动作、表演、灯光和声音指令统一为英文，只有对白使用选定语言。
- 日本语项目：剧本和分镜里可保留正常汉字，真正发送给 H3 时会用离线日语词典把对白转换成平假名读音。例如 `今日は図書館へ行きます。` 会发送为 `きょうはとしょかんへいきます。`。
- 最终语言处理结果会与当时的镜头内容绑定。之后修改镜头、对白或设置时，需要重新生成提示词，避免旧翻译误配新内容。
- 声线目标语言：保存到角色声线卡，告诉后续声音流程该角色的目标发音语言；它不占图片参考位。

角色、服装、道具、环境四类生成参考图合计最多 9 张。系统按“角色身份 → 环境 → 关键道具 → 服装”的顺序分配；同类超过 3 个时以本地拼图节省位置。声线使用独立的音频参考位（最多 3 条），不占这 9 张。

## 连续性与重做

- 全片风格、角色、服装、道具归属和空间方向会写入每个 H3 工程的制作上下文。
- 修改某段后，该段会标记“需重建”；它后面的已建工程也会提示重新确认连续性。
- 重建仍使用同一个工程 ID，不会悄悄另建重复工程。

## ComfyUI 视频工作流库

- 原有 H3/MMH3 工作流保持不变，始终排在第一项、作为默认项且不能删除。
- 在“视频工作流库”导入 ComfyUI 的 **API Format JSON**；也接受从队列/历史导出的、顶层带 `prompt` 的 API JSON。
- 为防止错误节点或任意工作流破坏现有流程，当前只接收可明确识别一个 MiniMax H3 条件节点和一个 `SaveVideo` 输出的 H3 兼容流程。
- 导入后，在每个分镜的“本段 ComfyUI 视频工作流”里独立选择。不同片段可以使用不同流程。
- Studio 仍统一注入当前片段的提示词、参考图、Seed 和项目输出目录；工作流本身保留它的其余节点结构。
- 自定义工作流可能调用 ComfyUI 自定义节点，只导入来源可信的 JSON。已经被某个片段引用的工作流不能删除，需先为这些片段改选其他流程。

## 项目管理、暂停与导出

- 顶部可搜索旧项目并分页浏览；项目多时不会一次铺满页面。
- “暂停任务”会阻止新的规划、提示词、视频生成和合片提交。已经进入 ComfyUI 的渲染不会强行冻结；如需停止可在结果区点“停止”，以后重新生成该段。
- 可导出整体剧情 Markdown 和逐集对白文本。
- “删除项目”只从长片制作列表移除记录，并把记录归档；已生成的 H3 分镜工程和视频文件保留。
- 界面记录剧集规划、分镜规划、提示词生成、采用版本视频生成和最终合并的本机实际耗时。

## ComfyUI 输出目录

每次生成都会获得独立目录，避免重跑时覆盖旧版本：

`ComfyUI/output/h3_prompt_studio/项目名/片段序号_片段名/任务短ID/video...`

项目名和片段名会自动清理 Windows 不允许的字符，但保留中文、日文和英文。实际目录也会显示在每段的视频结果旁。

## 本地与安全

- 制作清单保存在 D:\h3tool\data\productions。
- 删除的制作记录归档在 D:\h3tool\data\production_archive。
- 自定义视频工作流保存在 D:\h3tool\data\video_workflows。
- 每段 H3 工程仍保存在原来的 data\projects。
- Ollama 与 LM Studio 都受支持：在连接设置里填入当前本地服务地址，再从该服务实际返回的模型中自由选择，不使用硬编码模型白名单。带视觉能力的模型仅在需要分析图片时更有优势。
- ComfyUI 工作流保持原样；结构化提示词编译完成后会增加一次受校验的语言处理，不改变参考图绑定、镜头顺序或 ComfyUI 节点。
- 参考项目 D:\xiangmu\AI视频制作 未被修改。
