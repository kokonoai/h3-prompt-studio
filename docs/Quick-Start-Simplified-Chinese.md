# H3 Prompt Studio：首次安装与系列制作指南

适用：Windows 上的这套本地 H3 Prompt Studio。软件本身、ComfyUI、Ollama / LM Studio 是不同程序；安装本软件**不会**安装 H3 模型、ComfyUI 或本地 LLM。所有生成都在你配置的本机服务中执行。本指南对应当前定制版；只从上游 GitHub 重新克隆，不会自动带上本机新增的剧本管理、卡库和合片功能。

## 需要自己准备什么

| 类别 | 必需程度 | 用途和检查方法 |
| --- | --- | --- |
| Windows 10/11、可用磁盘空间 | 必需 | 程序、模型及成片需分别留空间；可把程序放在 `D:\h3tool`。 |
| `uv` | 必需 | 创建本程序独立的 Python 3.12 `.venv`；终端运行 `uv --version`。不必另装全局 Python。 |
| Node.js 22.12+（或 20.19+）及 npm | 首次安装必需 | 构建页面；运行 `node -v`、`npm -v`。 |
| FFmpeg 与 FFprobe | 合片必需，安装脚本也会检查 | 两个命令都要在 PATH 中：`ffmpeg -version`、`ffprobe -version`。 |
| ComfyUI 及 H3 模型/节点 | 生成视频必需 | 单独安装并运行；本程序只连接其本地 API，不代替安装。 |
| Ollama **或** LM Studio 加本地 LLM | AI 剧本/提示词必需 | 二选一即可；在软件连接设置中选已安装模型。手工编辑功能不依赖它。 |
| Krea 2 或 Z-Image 生图模型 | 卡图/关键帧可选 | 没有生图模型仍可上传自己的图片；不影响原视频流程。 |

默认 H3 参考图流程会检查相应的 ComfyUI 自定义节点（例如 `MiniMaxH3ReferenceToVideo`、`MiniMaxH3SigmaShift`、`H3SLAAttention`、`SaveVideo`）及模型。常用文件包括 `minimax_h3_ref2va_pruned_int8_convrot.safetensors`、`qwen3vl_32b_heretic_minimax_h3_nvfp4.safetensors`、`minimax_h3_video_vae_fp16.safetensors`、`minimax_h3_audio_vae_fp32.safetensors`、`minimax_h3_ref2v_turbo_8step_v1.0_768p_comfyui_bf16.safetensors`；其他模式或 8 步 LoRA 配方还会需要各自的模型和 LoRA。**以软件实际的“刷新模型/工作流检测”结果为准**，不建议把模型盲目复制进本程序目录。可选 Krea 2 生图配方需要 `krea2_turbo_bf16.safetensors`、`qwen3vl_4b_bf16.safetensors`、`qwen_image_vae.safetensors` 和对应节点。模型与节点请从你信任且有权使用的来源获取。

## 交付给另一台电脑前

只复制**当前定制版**程序源码和安装脚本，不要把自己电脑的 `data/`、`logs/`、`.venv/`、`frontend/node_modules/`、`dist/`、缓存或 `.env`/密钥文件一并交付。这些目录可能含私人剧本、图片、声音和视频。也不要把 `D:\xiangmu\AI视频制作` 混进安装包。新电脑安装后会自己建立独立数据和依赖。若要转移自己的项目，则另外备份 `data/`，不要混入给其他人的安装包。

建议放到例如 `D:\h3tool`，路径不要带空格或中文；当前脚本会以自身所在文件夹作为程序根目录，不要求一定是 D 盘。保留足够空间给视频结果。

## 第一次安装

1. 在 Windows 安装 `uv`、Node.js 22.12 或更高版本（含 npm；20.19+ 也可），以及 FFmpeg（`ffmpeg.exe`、`ffprobe.exe` 都可在终端直接运行）。安装来源与版本条件可直接看 `Setup.ps1`。装完重新开一个 PowerShell。
2. 将程序放到独立目录，直接双击 `Install-H3.bat`。它会把 Python 环境、uv/npm 缓存和前端依赖放在软件自己的目录内，并保留已有 `data/`。

3. 安装完成后双击 `H3-Start.bat`。需要看实时服务窗口时使用 `H3-Start-Visible.bat`；关闭后台服务使用 `H3-Stop.bat`。

4. 浏览器打开 `http://127.0.0.1:8766/`。安装器会建立程序目录下的 `.venv`，安装锁定的 Python 依赖，安装前端依赖并编译页面；不会修改系统 Python 或其他项目的虚拟环境。需要保留项目数据时，**不要删除 `data/`**。

如果浏览器打开后页面仍是旧版，先正常刷新；仍旧时按 `Ctrl+F5`。如果提示 8766 被占用，先确认占用者，不要盲目结束其他程序。服务日志位于 `logs/`。启动器只启动本软件服务，不会自动启动 ComfyUI 或加载 LLM。

更新后台代码后需要重启本软件服务。等当前视频任务全部完成，再运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\docs\Restart-H3-When-Idle.ps1`。脚本会先核对端口、进程和视频任务；只要仍有任务，就拒绝重启，不会中断视频。

## 接通本地模型

- 剧本规划和视频提示词：在本软件的连接设置中选 **Ollama** 或 **LM Studio**，再从你已安装的模型里选一个。没有固定必须使用的模型；较长剧本可先拆成多个项目分段，减少一次调用的上下文长度。
- 视频：先单独打开 ComfyUI，安装 H3 所需工作流、模型和自定义节点，确认本软件能连到它的本机地址。ComfyUI 忙于渲染时，响应会变慢；不要同时启动多个大型任务。
- 补图：仅在 ComfyUI 已有兼容的本地生图模型和节点时可用。到“设置”选择生图配方；“自动补环境关键帧”默认**关闭**。卡图和分镜关键帧也可先分析、人工审核，再单独或批量生成。

## 一个剧本、十集、每集多个项目

1. 在“角色资料库”建立或选择一套共享卡组。进入任意“剧集 / 片段 → 卡组与角色”，先“合并载入”这套卡组。角色、服装、道具、环境图、总图和角色声线样本都属于卡组资料。
2. 写本集前半段的项目 A，再写后半段的项目 B。每个项目可独立规划分镜、生成提示词和视频；项目标题建议包含集数与顺序，例如 `第01集-01 开场`、`第01集-02 转折`。
3. 如果在项目 A 中新增或补全卡片，点“同步到共享卡组”。然后在项目 B 中“合并载入”。**只点“保存卡库”不会同步独立卡组**。同步采用增量保留：B 的空白卡不会抹掉 A 已上传的图/音频；但若两边对同名卡都填了不同内容，后同步的非空字段优先，最好先人工核对。
4. 打开“剧本管理”，建立剧本并设定集数，选同一套共享角色资料。把各片段按观看顺序加入对应集，保存编排。资料库绑定只是管理关系，不会暗中覆盖任何片段。
5. 每个项目的视频都完成、采用版本选好之后，在剧本管理页检查齐备状态。可先点某一集的“合并本集”；勾选两集以上点“合并选中集”；全剧都齐后点“合并全剧”。不齐的集不会被其他项目的视频替补。结果会直接保存在本机，页面可预览并点“打开文件位置”；“另存副本”只是可选。

## 成片保存位置

项目内的分镜合片保存在 `data/production_films/<项目ID>/`；剧本管理合片保存在 `data/series_films/<剧本ID>/`，其中 `episodes/` 是单集，`selections/` 是选集合并，`<当前版本签名>/complete.mp4` 是全剧。不同采用版本使用不同签名，旧结果不会被覆盖。页面显示实际绝对路径，点“打开文件位置”比手动找 ID 方便。**不要在资源管理器中直接改名或移动正在被软件使用的成片**；要分享时可另存副本。原始 ComfyUI 视频和各片段项目仍保留。

“系列”只记录项目编排，项目本身和卡组独立存在。归档系列只归档编排，原项目、卡组、视频都保留。删除项目之前先确认你是否还要在系列中使用它；已丢失的项目不会被静默合并。

## 生成、审看和补图

- 在“分镜制作”里先核对每段长度（5–15 秒）、出场角色、对应图和对白。项目的一键生成会按顺序补视频提示词、渲染缺失片段并合成项目成片；已有完成版本不会因为再次点击而自动覆盖。
- “视频与成片”会在每段视频旁列出说话人和对白，方便逐段检查口型、声线与故事一致性。无对白会明确显示。审看后可只重做需要的单段。
- “自动补环境关键帧”是可选辅助步骤。开启后，一键生成在提示词之前只考虑**新场景、缺少环境参考、该段尚无关键帧**的片段，一次最多建议 3 张背景图；有环境卡图、总图或片段图时跳过。生成图作为该段规划上下文，不会擅自挤占 H3 最多 9 个参考图位，也不会生成角色或对白。设置页可先“预览建议”。
- 自动补图耗时并占显存；图像任务失败时一键流程会停止，不会继续提交视频。可保持关闭，按段手动上传/生成关键帧。

## 常见问题

- **卡组少了图或卡**：先检查当前项目是否只保存了自己的卡库；点击“同步到共享卡组”，然后在另一个项目重新“合并载入”。不要仅靠“系列”中的卡组下拉框。
- **页面空白**：查看浏览器开发者工具是否有资源 403/404；尝试 `Ctrl+F5`，确认 `dist/index.html` 存在、8766 是这套软件服务，并查看 `logs/`。
- **ComfyUI 超时**：确认本机地址、模型是否还在渲染及显存占用。网页可打开不代表 ComfyUI 空闲；等待当前任务完成后再发下一段。
- **LLM 输出截断**：按集/场景拆分剧本，减少一次规划的文本长度，或选择有足够上下文的本地模型。不要在生成中强行重新提交同一个任务。

安装或更新前，建议先备份 `data/`。切勿把别人的 `data/` 覆盖到自己的 `data/` 上。
